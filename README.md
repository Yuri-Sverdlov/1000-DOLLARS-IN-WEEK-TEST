# Online Retail report automation

Учебный проект: из неочищенного Excel-файла продаж создать воспроизводимый Excel-отчёт с помощью Python.

## Цель обучения

Мы не копируем готовое решение. Каждый этап отвечает на один практический вопрос: как прочитать данные, обнаружить проблему, выбрать правило очистки, проверить результат и объяснить его заказчику.

## Структура

- `src/` — Python-скрипты.
- `data/sample/` — маленькие безопасные учебные выборки, которые хранятся в Git.
- `data/input/` — полный исходный файл; Git его не отслеживает.
- `output/` — созданные отчёты; Git их не отслеживает.
- `docs/` — конспекты и решения, принятые в процессе.
- `tests/` — автоматические проверки.

## Данные

Источник: [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii).

Скачайте `online_retail_II.xlsx` и поместите его в `data/input/`. Не добавляйте этот большой исходный файл в обычный Git-репозиторий.

## Первое занятие

Мы начнём с небольшой выборки: откроем таблицу, узнаем её столбцы и найдём четыре типа проблем — дубликаты, пустой идентификатор клиента, нулевую цену и возврат. Затем сформулируем правила: что удалять, что сохранять и почему.
