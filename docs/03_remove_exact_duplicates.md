# Занятие 3. Первая безопасная очистка

## Что делает скрипт

`src/03_remove_exact_duplicates.py` читает первые 5 000 строк листа `Year 2010-2011`, удаляет только точные копии и сохраняет новый файл:

```text
output/01_without_exact_duplicates.xlsx
```

Исходный `online_retail_II.xlsx` не меняется.

## Почему сохраняется первая строка

Для пары одинаковых строк нет разницы, какую из них оставить: в каждой одинаковы счёт, товар, количество, цена, дата, покупатель и страна. Мы сохраняем первую исключительно как понятное и стандартное правило. Она представляет одну реальную операцию; остальные копии создают ложную выручку и ложное количество товаров.

## Что означает `drop_duplicates()`

```python
clean_sales = raw_sales.drop_duplicates().copy()
```

- `raw_sales` — исходные данные в памяти.
- `drop_duplicates()` строит новый набор строк без точных повторов.
- `.copy()` явно создаёт независимую таблицу, с которой мы будем работать дальше.

## Две проверки

Скрипт не должен просто «надеяться», что всё получилось.

1. Он сравнивает количество удалённых строк с количеством найденных лишних копий.
2. Он вновь открывает созданный Excel и проверяет число строк в сохранённом файле.

Если проверка не пройдёт, Python остановится и покажет ошибку. Это хорошо: лучше остановиться, чем незаметно передать заказчику неверный отчёт.

## Как запустить

```powershell
python src/03_remove_exact_duplicates.py
```

Ожидаемый результат для этой выборки:

```text
Исходных строк: 5,000
Удалено точных копий: 79
Осталось строк: 4,921
```
