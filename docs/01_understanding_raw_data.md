# Занятие 1. Как прочитать данные до очистки

## Цель

До исправления ошибок нужно понять, что означает каждая строка и какие правила нельзя нарушать. Скрипт `src/01_explore_data.py` читает только первые 5 000 строк одного листа. Он не меняет Excel-файл и не создаёт отчёт.

## Как запустить

В корне проекта выполните:

```powershell
python -m pip install -r requirements.txt
python src/01_explore_data.py
```

Если на компьютере несколько версий Python, замените `python` на `py`.

## Что означает одна строка

Одна строка — одна товарная позиция в счёте, а не один заказ. Поэтому одинаковый `Invoice` в нескольких строках — обычно нормально: покупатель купил несколько товаров.

| Столбец | Значение |
| --- | --- |
| `Invoice` | Номер счёта. Значение, начинающееся с `C`, указывает на возврат. |
| `StockCode` | Код товара или служебной операции. |
| `Description` | Название товара. |
| `Quantity` | Количество единиц. Отрицательное значение — признак возврата. |
| `InvoiceDate` | Дата и время счёта. |
| `Price` | Цена одной единицы. |
| `Customer ID` | Идентификатор покупателя. Может отсутствовать. |
| `Country` | Страна покупателя. |

Выручка не записана в файле отдельно. Для обычной строки она рассчитывается так:

```text
LineRevenue = Quantity × Price
```

## Четыре наблюдения, которые вы должны сделать

1. Пустой `Customer ID` не всегда означает, что строку надо удалить. Для топа клиентов такая строка бесполезна, но для общей выручки может быть нужна.
2. Нулевая `Price` не даёт выручки. Сначала посмотрим на примеры и выясним, это ошибка или служебная запись.
3. Возврат не надо просто выбрасывать. Он уменьшает выручку и нужен для отдельного показателя «процент возвратов».
4. Полные дубликаты можно считать кандидатами на удаление, но одинаковые товары в одном счёте ещё не обязательно являются дубликатами. Сначала сравнивают все поля строки.

## Ваше первое действие

Запустите скрипт и пришлите мне первые 30–50 строк вывода, особенно блоки «Пустые значения», «Полностью одинаковые строки» и три группы примеров. Затем вместе сформулируем правила очистки до того, как напишем первый очищающий скрипт.
